Hermes

Hermes is a personal assistant that Charlie (GitHub: starpastoral) runs on the owner’s own computers for personal use. It is not a public service and has no other users.

What it does

  • Reads the owner's Gmail (read-only) to sort incoming mail and flag messages that need attention.
  • Reads the owner's Google Calendar to include upcoming events in a morning and evening summary.
  • Sends those summaries and reminders to the owner's own Telegram chat.

Google user data

Google data is used only to produce these summaries for the owner. It is processed on the owner's own machines, is not sold, and is not shared with any third party. See the privacy policy.
